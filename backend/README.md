# ParaSwap Backend (Go)

Minimal HTTP stub for a future API/indexer service. Contract ABIs and addresses are **not** checked in as source of truth — they are generated by the monorepo contract build.

## Contract artifacts

From the repo root:

```bash
npm run build:contracts
```

This runs Hardhat compile + `blockchain/scripts/export-artifacts.ts`, which:

1. Writes ABIs to `packages/contracts/src/abis/` (`@para-swap/contracts`)
2. Copies ABIs to `backend/contracts/abis/`
3. Writes `backend/contracts/addresses.json` from `packages/contracts/src/addresses.ts`

Re-run `npm run build:contracts` whenever Solidity changes or deployed addresses change (via env vars).

## Run locally

```bash
cd backend
go run .
```

Endpoints:

| Path | Description |
|------|-------------|
| `GET /health` | Liveness probe |
| `GET /contracts` | Lists synced ABI JSON filenames |
| `GET /addresses` | Mainnet/sepolia address snapshot |

Environment:

| Variable | Default | Purpose |
|----------|---------|---------|
| `PORT` | `8080` | HTTP listen port |
| `ETHEREUM_RPC_URL` | — | Reserved for future on-chain reads |

Set `PARASWAP_ADDRESS`, `POOLS_FACADE_ADDRESS`, etc. before `build:contracts` so they appear in `addresses.json`.
